# 揽星阁 AI 智能体编排引擎

> 软件设计说明书（用于软件著作权登记与高新技术企业文化产品论证）

## 一、系统概述

揽星阁 AI 智能体编排引擎（Lanxingge Agent Orchestrator）是一套面向多智能体协作的
任务编排与调度软件。系统将大语言模型能力、工具调用、记忆管理与任务规划封装为可组合
的执行单元，支持顺序流水线、并行扇出、层级主管-工人等多种协作拓扑，可作为检索增强、
推理调度、提示词评测等上层 AI 能力的技术底座。

## 二、运行环境

- 操作系统：Windows / Linux / macOS
- 运行环境：Python 3.10 及以上
- 依赖：标准库即可离线运行；接入真实模型网关时可选 `requests`

## 三、总体架构

```
┌─────────────────────────────────────────────┐
│                 Orchestrator 编排器            │
│   顺序 / 并行 / 层级主管-工人 拓扑调度          │
├─────────────────────────────────────────────┤
│   Agent 智能体    │   Planner 规划器           │
│   Memory 记忆     │   ToolRegistry 工具注册    │
│   LLMClient 模型客户端（可替换后端）           │
└─────────────────────────────────────────────┘
```

## 四、功能模块说明

| 模块 | 职责 |
|---|---|
| `LLMClient` | 统一对话接口，屏蔽不同模型后端差异；内置 `MockLLMClient` 离线联调 |
| `Tool` / `ToolRegistry` | 工具抽象与注册中心，扩展 Agent 执行能力 |
| `MemoryStore` | 短期对话缓冲 + 长期键值记忆 |
| `Planner` | 将目标拆解为有序子任务 |
| `Agent` | 单个智能体执行单元，组合提示词、记忆与工具 |
| `Orchestrator` | 多智能体注册与拓扑调度 |
| `Runtime` | 执行状态跟踪与异常捕获 |

## 五、核心处理流程（层级模式）

1. 主管智能体调用 `Planner.decompose` 将目标拆解为子任务；
2. 各工人智能体基于子任务独立执行；
3. 主管汇总工人结果并生成最终答复。

## 六、使用方法

```bash
cd lanxingge-agent-orchestrator
python examples/demo.py
```

接入真实模型时，实现 `LLMClient.complete` 或改用 `OpenAICompatibleClient` 即可，
其余编排逻辑无需改动。

## 七、软件特点

- **后端无关**：模型客户端可插拔，便于对接私有化部署；
- **拓扑灵活**：一套引擎覆盖顺序、并行、层级协作；
- **可观测**：内置日志与运行时状态跟踪；
- **易扩展**：工具与智能体以注册方式接入。
